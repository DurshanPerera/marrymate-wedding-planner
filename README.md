# 💍 MarryMate – Smart Wedding Planning System

## 📌 Overview

**MarryMate** is a modern web-based wedding planning platform designed to simplify and streamline the entire wedding planning process. It provides a centralized solution where users can discover vendors, manage budgets, book services, and communicate efficiently.

Traditional wedding planning is often fragmented, time-consuming, and inefficient. MarryMate solves these problems by integrating all essential functionalities into a single platform.

---

## 🚀 Key Features

### 👩‍❤️‍👨 Customer Features

* 🔍 Vendor discovery and filtering by category & location
* 💰 Smart Budget Planner with automated allocation
* 📅 Wedding timeline management
* ❤️ Save and favorite vendors
* 💬 Direct communication with vendors
* 🧾 Booking and payment requests

### 🧑‍💼 Vendor Features

* 📝 Profile and service management
* 📦 Add, edit, and delete service packages
* 📊 View booking requests and analytics
* 💬 Communicate with customers

### 🛠️ Admin Features

* ✅ Vendor verification and approval
* 👥 User management
* 📂 Category and system management
* 📊 Monitoring and reporting

---

## 🤖 Unique Features

### 🔗 AI-Based Web Scraping

* Automatically extracts vendor details from websites
* Keeps vendor data updated
* Reduces manual data entry

### 💡 Smart Budget Planning

* Allocates budget based on predefined logic
* Recommends vendors within budget

## 🏗️ System Architecture

The system follows a **client-server architecture**:

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Firebase (Authentication, Firestore, Storage)
* **Hosting:** Firebase Hosting
